# Локальная проверка периодов ДС и размещения — 14.11.2026

Стенд: PMS `http://localhost:5273/tariffs`, гостиница `benamar-hotelspa`.
Тариф, созданный через браузер: **QA — ДС и размещение 1–3 гостя**, код
`QA_DS_GUESTS`. Договор: `QA-DS-2026-11`, партнёр: «QA — периоды ДС и гости».
Данные оставлены для ручной проверки. Коммит и выпуск не выполнялись.

## Подготовка

Из `backend/`, с существующим локальным `.env`:

```powershell
# Только показать состав и целевую гостиницу
node --env-file=.env scripts/seed-tariff-periods.cjs --tenant=benamar-hotelspa
# Создать/обновить только данные этой QA-фикстуры
node --env-file=.env scripts/seed-tariff-periods.cjs --tenant=benamar-hotelspa --apply
```

Скрипт допускает только loopback PostgreSQL и запрещает `NODE_ENV=production`.
Добавляет отдельного QA-партнёра без ключей доступа, его юрлицо, договор,
три ценовых документа и две категории. Существующие договоры и категории
гостиницы не перезаписывает. Повторный запуск не создаёт дубликаты документов.
Тариф создаётся штатным мастером из строки условий договора: экипаж, любая
авиакомпания, без питания. Физические номера и бронирования не создаются.

Это фикстура полученных PMS сеток (`PartnerContractPrice.fill`), а не проверка
передачи из Авии: HTTP-синхронизация между системами здесь не выполняется.
Цены хранятся в сетках в копейках; ниже приведены отображаемые рубли.

## Браузерная проверка

- Предпросмотр договора и шаг «Проверка» мастера показывают три периода,
  правильные цены, границы и НДС.
- Тариф сохраняется через мастер. В сохранённом тарифе проверены все три
  периода и ставки 0 / 5 / 10%.
- Календарь на 14 дней: цены на 2 гостей меняются 14 и 20 ноября, 19 ноября
  остаётся прочерк; в календаре на 3 гостей весь ДС №1 остаётся без цены.
- Календарь на 30 дней: ДС №2 включает 27 ноября; с 28 ноября прочерки.
  Переход на неделю назад также показал прочерки до 7 ноября.
- Причины прочерков различаются: нет цены на размещение, превышение
  вместимости, дата вне срока цен.
- Двойная вертикальная прокрутка воспроизведена и исправлена: абсолютные
  скрытые `caption` таблиц теперь ограничены контейнером таблицы. До исправления
  высота документа была 1341 px при окне 871 px, после — 871 px, прокручивается
  только раздел. На ширине 390 px документ равен окну 390×844 px, также один
  вертикальный контейнер. Горизонтальная прокрутка широких таблиц сохранена.
